# More DSA Topics

Code, notebooks and whiteboard notes for the data structures and ideas that sit around recursion. Each folder has its own page that explains what is inside.

| Topic | What's inside | Notebooks and code | PDFs |
|---|---|---|---|
| [Arrays](arrays/) | How arrays work under the hood: a short set of notes and a notebook that builds a dynamic array (a Python-list look-alike) from scratch with `ctypes`. | 1 | 1 |
| [Time and Space Complexity](time-and-space-complexity/) | Big-O in practice: how to count the work an algorithm does, why growth rate matters on large inputs, and how recursion uses memory. Notebooks time real code (merge sort against bubble sort) and plot the growth. | 10 | 4 |
| [Linked List](linked-list/) | Build a singly linked list step by step: the node, taking input, length, insert, delete and search, each written iteratively and recursively. The complete code notebook puts everything in one place. | 9 | 4 |
| [Stack](stack/) | The last-in, first-out structure, built on a list, an array, a dynamic array and a linked list. | 1 | 1 |
| [Queue](queue/) | The first-in, first-out structure, built on an array, a list and a linked list. | 1 | 1 |
| [Trees](trees/) | Generic trees, binary trees and binary search trees: nodes, traversals (inorder, preorder), and BST operations, nearly all of them recursive. | 5 | 5 |
| [Hashmaps](hashmaps/) | Hash tables from the ground up: hashing, collisions, and open addressing with linear probing. | 2 | 1 |
| [Dynamic Programming](dynamic-programming/) | A starting point for dynamic programming: the prerequisites (recursion, lists, 2D lists, indexing) and the Fibonacci recursion that DP optimises. | 1 | 0 |

Suggested order: [arrays](arrays/) → [time and space complexity](time-and-space-complexity/) → [recursion](../recursion/README.md) → [linked list](linked-list/) → [stack](stack/) and [queue](queue/) → [hashmaps](hashmaps/) → [trees](trees/) → [dynamic programming](dynamic-programming/). The full plan is in the [roadmap](../roadmap/README.md).
