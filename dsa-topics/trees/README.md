# Trees

Generic trees, binary trees and binary search trees: nodes, traversals (inorder, preorder), and BST operations, nearly all of them recursive.

**Before you start:** Recursion (the main course): tree code is recursion on nodes.

|---|---|

| [💻 `types-of-binary-tree.py`](code/types-of-binary-tree.py) | ASCII diagrams of the types of binary tree (full, perfect, complete, balanced, degenerate). Run it to print them. |
